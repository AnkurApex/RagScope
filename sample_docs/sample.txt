RAGScope is a production-grade AI platform designed to execute Retrieval-Augmented Generation at scale. It ensures that language models remain faithful to the provided context. RAGScope utilizes ChromaDB for storing dense vectors representing textual information, and PostgreSQL for logging extensive telemetry. The telemetry data includes token usage, latency metrics, and user feedback scores (thumbs up and thumbs down). It also contains a suite of automated evaluations built on top of the DeepEval and Ragas frameworks, which test for both answer relevancy and contextual faithfulness. RAGScope's primary mission is to eradicate AI hallucinations in enterprise settings.
